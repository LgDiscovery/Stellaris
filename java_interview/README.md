## 四、六个模块的能力主线

### 01 · JVM —— 「能讲清原理，更能查线上问题」
一面考内存结构与 GC 基础；二面必然追到**线上排查**：频繁 Full GC、CPU 100%、内存泄漏、容器内 OOMKilled。
简历写了「熟悉 JVM」，就要准备好从 `jstat` 看到异常 → `jmap` dump → MAT 定位支配树 → 定位到具体代码的完整链路。

### 02 · Java 并发编程 —— 「线程池参数能落地，不是背 7 个参数」
重点不是背 API，而是：线程池核心数**怎么算**、为什么不用 `Executors`、`ThreadLocal` 怎么泄漏、`CompletableFuture` 怎么把串行接口并行化。
结合简历：**用并发改造串行调用把接口耗时从 800ms 降到 200ms**，是很好的项目话术。

### 03 · 集合与 Java 基础 —— 「源码级回答」
`HashMap` 的 `hash()` 扰动、`resize()` 里的 `(n-1) & hash`、树化阈值 8 与 6 的不对称、`ConcurrentHashMap` 从 JDK7 分段锁到 JDK8 CAS+synchronized 的演进——这些是高级岗和初级岗的分水岭。

### 04 · Spring 全家桶 —— 「@Transactional 失效」必须答全
简历写了「熟练 Spring」，面试官一定会往深里问：三级缓存解决循环依赖、Bean 生命周期、自动装配 SPI 演进、**@Transactional 失效的 8 种场景**。
这块答不全，会直接影响「熟练」这个自我评价的可信度。

### 05 · 云原生与可观测性 —— 「把简历数字讲成故事」
这个模块是**简历业绩的主战场**。面试官问「你简历说发布从 4 小时缩短到 15 分钟，具体怎么做到的？」时，你要能拆成：镜像分层缓存 + 多阶段构建 + Pipeline 分阶段并行 + 环境配置分离 + 一键回滚。
同理还有「故障率降 82%」「异常发现小时级→分钟级」「80% 异常自动修复」。

### 06 · 基础与场景设计 —— 「9 年经验的分水岭」
网络/OS 基础是及格线；**场景设计题才是定级的关键**。
期权风控实时预警、规则引擎零代码配置、主备双活协同调度、任务依赖调度、数据链路端到端不丢不重不乱序——这些题目直接对应简历里的项目，提前准备好结构化答题框架（分层拆解 → 技术选型 → 权衡取舍 → 落地风险）。
